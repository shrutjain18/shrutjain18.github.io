My Projects

Mini Submarine / ROV System

Embedded Systems & Telemetry Integration

Developing a custom 4kg displacement remotely operated underwater vehicle featuring a 3L inner hull. The system is controlled via an ESP32-S3 microcontroller, bridging a 433MHz telemetry radio to a self-contained WebSerial HTML dashboard for real-time monitoring. Integrated hardware includes an MPU6050 IMU, SEN0257 water pressure depth sensor, Skywalker 40A ESCs, and precision dive plane servos.

Predictive Maintenance Framework for Industrial Motors

Tata Steel (Gamharia Plant) - Engineering Internship

Analyzed 98 historical plant motor failure logs using FMEA and Why-Why analysis to develop a multi-parameter Health Index (HI) predictive maintenance framework. Engineered a Cross-Coupled Penalty Matrix and a Power-Law fatigue algorithm to extrapolate Remaining Useful Life (RUL) for heavy industrial AC/DC motors, optimizing maintenance schedules based on data-driven physical degradation modeling.

4-DoF Robotic Arm

Closed-Loop PID Control

Engineered a 4-Degree-of-Freedom robotic arm featuring closed-loop PID control using dual ESP32 microcontrollers. The system utilized DC encoder motors and potentiometer feedback mapping to achieve precise articulation and movement. Successfully showcased this hardware build at TechEvince 12.0.
